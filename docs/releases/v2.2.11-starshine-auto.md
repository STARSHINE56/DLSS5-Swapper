# DLSS 5 Swapper · Starshine Auto 2.2.11

这是 STARSHINE56 基于 [rakanki911/DLSS5-Swapper](https://github.com/rakanki911/DLSS5-Swapper) 的非官方 Fork，遵循 MIT 许可证。保留原作者 Rakan Alkhaldi 和贡献者署名。

## 本次更新

- 修正多显卡判断：显卡型号与驱动来自同一张卡；无法确定游戏实际使用的显卡或驱动未知时，降低推荐置信度并说明原因。
- 智能检测、安装规划和安装统一使用保存的手动 API 设置，保留原始扫描结果；间接 API 字符串证据不再获得最高置信度。
- 明确指定的游戏 EXE 缺失时不再替换为其他程序；运行验证使用实际安装目标和路线，避免把启动器当成游戏。
- 普通组件加载成功不再被当成神经渲染生效。成功需要对应路线中神经功能创建和成功执行的日志证据；Feeder 还需要实际帧传输或执行证据。
- 安装时记录日志基线，排除旧成功会话；区分游戏与 host 日志、普通帧传输和神经执行，改进长日志和读取失败处理。
- 修正卸载后、后续运行失败和 Last Known Good 状态；已有正常配置继续保留。
- 修复建议仅在有对应加载失败证据时出现；旧异步检测结果不再覆盖新的游戏或模式，失败状态正确显示。
- 新增 23 项检测、运行验证、IPC 和界面回归测试。

本次修改集中于 Starshine 自动化层及相关智能界面。上游反作弊、原版扫描、核心兼容规则、安装与恢复逻辑保持原样。

## 使用说明

安装后启动游戏，进入实际渲染场景，再执行运行验证。旧安装记录第一次检查可能先建立日志基线，需要再运行一次游戏才能验证。日志检测只能确认记录中的执行证据，不能验证画质改善或 FPS；不同显卡和游戏仍可能存在兼容差异。遇到问题优先使用 **Restore Originals**。
